# KNN Classification Project (Iris Dataset)

This project implements a K-Nearest Neighbors (KNN) classification model using Python and Scikit-Learn on the Iris dataset.

## Project Files

- `Model Training.py` / `m.py` - Core machine learning model training script[cite: 1].
- `knn.docx` - Detailed project report[cite: 1].
- `Optimal_k.py` - Script to find the optimal k value.
- `Setup_and_Data_Splitting.py` - Data preprocessing and splitting script.

## Requirements

To run this project, make sure you have the following Python libraries installed:

```bash
pip install numpy pandas scikit-learn matplotlib
```
